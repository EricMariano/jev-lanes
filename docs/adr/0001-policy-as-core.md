# Política de decisão e escalada como núcleo

O projeto terá como contribuição central uma política explícita para aceitar a
decisão do Jev, consultar um modelo de reserva ou solicitar revisão humana. Essa
direção foi escolhida com o autor em vez de concentrar o produto na redução de
código com `attach()`. A API de conveniência deverá expor o comportamento da
política, e sua avaliação deverá medir qualidade e escaladas além de linhas economizadas.
